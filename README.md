# Workspace Name Wrap

English | [中文](README.zh.md)

Wrap long workspace names within the sidebar width. Rows grow with their contents while workspace titles and directory names remain unchanged.

The plugin uses DSH extension points and leaves with its bundle when disabled. It adds no tools, model prompts, external requests, or conversation records.
